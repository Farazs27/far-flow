# Feedback and contributions

Bug reports and focused feature suggestions are welcome through GitHub Issues. Include your macOS version, Mac chip, app version, selected language, cleanup mode and steps to reproduce. Use synthetic sample text; do not post recordings, dictation history, exports, credentials or private documents.

This repository is publicly viewable with all rights reserved. It does not grant an open-source license. Please discuss proposed code contributions with the maintainer before opening a pull request. Do not submit third-party proprietary code, extracted app assets or model weights.

For local development, read [BUILDING.md](docs/BUILDING.md), [ARCHITECTURE.md](docs/ARCHITECTURE.md) and [VERIFICATION.md](docs/VERIFICATION.md). Keep changes to project settings in `project.yml` and regenerate the Xcode project. Run the relevant native unit checks for behavioral changes and inspect the actual macOS UI for interface changes.
