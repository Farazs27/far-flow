# Far Flow identity

The current identity pairs a single flowing F with warm ivory, charcoal and restrained olive signals. Zalando Sans provides the custom interface hierarchy; native macOS controls and SF Symbols retain platform behavior.

| Token | Light | Dark |
| --- | --- | --- |
| Workspace | `#F6F3EB` | `#24231F` |
| Ink | `#181815` | `#F1EDE3` |
| Secondary | `#625F57` | `#BDB7AA` |
| Rule | `#D8D3C8` | `#4C4941` |
| Olive | `#596D43` | `#BBC88A` |

The charcoal sidebar anchors both appearances. The sculptural travertine banner is production artwork, with controls kept outside the image. The persistent recording capsule stays dark and uses a waveform rather than live transcript words.

The active app icon is `AppIconStudio`. The scalable mark and full icon master are under `brand/assets/`; production banner and icon sizes are in the asset catalog. Font license texts accompany the fonts in app resources. Original branding and artwork are reserved under the root [LICENSE](../LICENSE).

The [light](images/far-flow-light.png) and [dark](images/far-flow-dark.png) images are actual native captures with sample history, cropped at the top to omit a macOS capture indicator. No interface content was generated or retouched for those screenshots. The banner is branded artwork used by the app.

## Repository sharing image

`docs/images/far-flow-social-preview.png` is the 1280 × 640 PNG for GitHub's repository Social preview setting. It uses the current mark, ivory/charcoal identity and travertine artwork. The image was produced with the built-in image-generation tool; its prompt is recorded in `brand/assets/far-flow-social-preview.prompt.txt`.

After replacing this asset, upload it again under the repository's Settings → General → Social preview. Committing the image alone does not change GitHub's link preview.
